🎮 Gaming Hub – Multi-Level Java Console Game
<br>
<br>
Gaming Hub is a group project developed using Java, focused on creating an engaging multi-level console-based game.
<br> 
The game is designed with increasing difficulty levels, where players can only progress by winning the current stage.
<br>
🕹Features added :
<br>
🔐 Level Unlock System: Each level unlocks after the previous one is cleared
<br>
🎯 Dynamic Difficulty: Challenges increase as the player moves forward
<br>
🧠 Logical & Interactive Gameplay: Encourages problem-solving and engagement
<br>
🧑‍💻 OOP-based Structure: Clean modular code using Object-Oriented Programming concepts
<br>
<br>
🧰 Tech Stack & Concepts:<br>
Java for development
<br>
OOPs Concepts like inheritance, polymorphism, and abstraction
<br>
Control Flow & Loops for game logic
<br>
Scanner for real-time user input
<br>

I actively contributed to the game logic and structure, ensuring smooth level transitions and intuitive user interaction.
<br>
This project strengthened my logical thinking and understanding of Java-based game development.
